# CraftPages docs

CraftPages is a free, open-source desktop CMS for plain-HTML static sites. It opens the site
folder you already have, lets you edit text, images and SEO right on the page, adds a blog in
your own design, and publishes to Cloudflare or any web host over FTP / SFTP.

## Start here

1. [[Installing]]: download and first launch on macOS, Windows and Linux.
2. [[Your site folder]]: where your site lives and what gets published.
3. Where to publish: [[Setting up Cloudflare]] (free hosting; account, Account ID and API
   token, step by step) or [[Publishing to a web host]] (your hosting, over FTP or SFTP).
4. [[Publishing]]: publish, publish history and rolling back.
