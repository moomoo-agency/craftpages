# CraftPages docs

CraftPages is a free, open-source desktop CMS for plain-HTML static sites. It opens the site
folder you already have, lets you edit text, images and SEO right on the page, and publishes
to Cloudflare.

## Start here

1. [[Installing]]: download and first launch on macOS, Windows and Linux.
2. [[Your site folder]]: where your site lives and what gets published.
3. [[Setting up Cloudflare]]: account, Account ID and API token, step by step.
4. [[Publishing]]: publish and roll back.
